# EcoConnect – Community Environmental Conservation System

## Features
- User registration and login
- Environmental issue reporting with photo and location
- Admin verification and issue status tracking
- Community environmental activities
- Green Points system
- Leaderboard
- Admin dashboard
- SQLite database

## Run in PyCharm / VS Code

1. Install Python 3.10 or newer.
2. Open this folder as a project.
3. Open Terminal.
4. Install dependencies:

   pip install -r requirements.txt

5. Start the application:

   python app.py

6. Open:

   http://127.0.0.1:5000
